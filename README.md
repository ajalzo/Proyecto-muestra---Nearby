Paso a paso para abrirlo

Instalá Python desde python.org/downloads. En el instalador tildá “Add python.exe to PATH” antes de instalar.

Poné los archivos juntos en una carpeta nueva, por ejemplo C:\Users\LAB3-PC14\Documents\nearby. Los que importan son app.py, .gitignore y .env.example.

Abrí una terminal en esa carpeta: entrá a la carpeta, hacé clic en la barra de direcciones del Explorador, escribí cmd y apretá Enter.

Ejecutá python app.py. Se abre el navegador en http://127.0.0.1:8000. Para cerrarlo, presioná Ctrl + C en la terminal.

Para ver o editar el código, hacé clic derecho sobre app.py y elegí “Abrir con” y Bloc de notas o IDLE. Con Visual Studio Code (code.visualstudio.com) se lee mucho mejor. El servidor está al principio del archivo y la página completa viene después, desde la línea PAGINA = r""".

Para activar la IA con Claude (opcional): copiá .env.example como .env y pegá tu clave después de ANTHROPIC_API_KEY=. Después reiniciá el programa.
